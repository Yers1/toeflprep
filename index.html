Questions

No. This is an independent practice tool. Scoring is based on ETS-published specifications and rubrics, but only ETS can issue official scores.
Speaking and writing tasks require evaluating free-form responses. We use your own LLM key (GitHub Models, Gemini, DeepSeek, OpenAI, or Anthropic) so there is no backend cost and your data stays with you.
Speech recognition works best in Chrome, Edge, or Safari on desktop and Android. iOS Safari support varies. For the most reliable experience, use Chrome on a laptop.
Reading and writing tasks work offline once the page is loaded. Speaking tasks need the browser's speech recognition, which requires a network connection.
