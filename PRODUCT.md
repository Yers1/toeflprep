# Product

## Audience

Students preparing for the TOEFL iBT format introduced in January 2026. They are often working under university deadlines and need focused practice that distinguishes real evidence from score theater.

## Product purpose

TOEFL Prep is an independent, browser-based practice environment for all 12 current task families. It combines original objective sets, optional rubric-aligned feedback for free-form responses, and a local dashboard that recommends what to practice next.

## Product principles

1. **Current format first.** Coverage and timing follow public ETS descriptions for the 2026 test.
2. **Accuracy before confidence.** Objective tasks explain answers and distractors.
3. **Honest estimation.** The app never presents a practice conversion as an official TOEFL score.
4. **Actionable history.** Attempts should change the next recommendation, not merely fill a log.
5. **Privacy by default.** No account is required; API-key persistence is opt-in.
6. **Original content.** Practice material is authored for this project and does not reproduce ETS questions.

## Success criteria

- A learner can practice each official task family without creating an account.
- Every objective response receives a clear explanation.
- The dashboard identifies missing coverage and recent weak sections.
- The product remains usable without an API key.
- Timers and scoring claims avoid false precision.

## Accessibility

- WCAG 2.1 AA target
- keyboard-visible focus states
- semantic fieldsets for answer choices
- reduced-motion support
- responsive layout for phone and laptop widths
