# План платформы TOEFL Prep 2026 (v3, полная перестройка)

## Цель

Платформа, на которой можно подготовиться к новому TOEFL iBT от диагностики до финального
пробного теста. Главный упор на **Writing и Speaking**: каждая попытка оценивается по осям
официальных рубрик ETS, а не абстрактной «оценкой ИИ», и пользователь видит, что именно
мешает подняться на следующий балл.

## Принципы

1. **Точный формат 2026.** Тайминги, число заданий, адаптивные модули, шкала 1–6.
2. **Оценка по официальным осям.** Все W/S-оценки раскладываются по критериям рубрик ETS.
3. **Работает без ключа.** Локальные анализаторы дают оценку и метрики без AI; AI уточняет.
4. **Честность.** Баллы — оценка, не официальный результат. Где мы не можем измерить (например, произношение без AI), так и говорим.
5. **Оригинальный контент.** Вопросы ETS и других сайтов не копируются — на них ведут ссылки.
6. **Без сборки.** Статический сайт (ES-модули) + одна опциональная serverless-функция на Vercel.

## Карта экранов

```
#/                 Главная: статус подготовки, «сегодня по плану», быстрый старт
#/practice         Все 12 типов заданий, сгруппированы по секциям, с прогрессом
#/practice/:task   Тренажёр одного задания (режим практики: подсказки, мгновенный разбор)
#/tests            Список полных mock-тестов + секционных тестов + внешние тесты
#/test/:id         Прохождение теста (режим экзамена: строгие таймеры, без подсказок)
#/report/:attempt  Отчёт по тесту: баллы 1–6, CEFR, 0–120, разбор по заданиям
#/criteria         Критерии оценки: рубрики W/S, конвертация, CEFR, чек-листы, примеры ответов
#/plan             Персональный план: дата теста, цель, часы в неделю → расписание
#/resources        Каталог официальных и сторонних практик-тестов
#/history          Все попытки, фильтры, экспорт/импорт JSON
#/settings         AI-провайдер, голос озвучки, микрофон, тема
```

## Тренажёры Writing

| Задание | Интерфейс | Локальная оценка | AI-оценка |
|---|---|---|---|
| Build a Sentence | Реплика собеседника, плитки слов (клик/клавиатура), таймер 5:50 на 10 | Точное совпадение 0/1, разбор правильного порядка | — |
| Write an Email | Ситуация + 3 цели, таймер 7:00, счётчик слов | Чек-лист целей, приветствие/подпись, регистр, разнообразие предложений, повторы, копирование из задания → оценка по 4 осям | Балл 0–5 + разбор по осям + исправления ошибок + версия на 5 |
| Academic Discussion | Профессор + 2 студента, таймер 10:00 | Объём (100+), позиция, примеры/объяснения, ссылка на одноклассников, разнообразие, копирование | Балл 0–5 + разбор по осям + исправления + версия на 5 |

## Тренажёры Speaking

| Задание | Интерфейс | Локальная оценка | AI-оценка |
|---|---|---|---|
| Listen and Repeat | Сцена + 7 предложений, TTS один раз, окно ответа 8–12 с, запись | Выравнивание распознанного текста по словам → балл 0–5 по правилам официальной рубрики; подсветка пропусков/замен | — (уже детерминировано) |
| Take an Interview | Интервьюер (TTS), 4 вопроса, 45 с на ответ, без подготовки | Длительность речи, WPM, число и длина пауз (анализ громкости микрофона), слова-паразиты, связки, лексическое разнообразие, релевантность → оценка по 4 осям | Балл 0–5 по 4 осям с учётом метрик + улучшенный ответ |

Все ответы записываются (MediaRecorder) — их можно переслушать и сравнить.
Распознавание речи — Web Speech API (Chrome/Edge). Где его нет — ручной ввод транскрипта.

## Полные mock-тесты

- 2 полных теста в формате 2026: Reading (M1 → маршрут → M2 hard/easy), Listening (так же), Writing (10 + 1 + 1), Speaking (7 + 4).
- Порог маршрутизации: ≥ 60 % в модуле 1 → «hard» модуль.
- Секционные таймеры, автопереход, запрет возврата к прошлому модулю (как на экзамене).
- Отчёт: баллы секций 1–6, общий балл (среднее, округление до 0.5), CEFR, сопоставимый 0–120, разбор каждого ответа.

### Модель подсчёта (оценочная)

- Reading/Listening: доля верных → «сырой» 0–30 с учётом маршрута (easy-маршрут ограничен сверху) → официальная таблица конкордации → band.
- Writing: Build a Sentence (доля верных × 5) · 0.3 + Email · 0.3 + Discussion · 0.4 → 0–5 → band.
- Speaking: среднее 11 ответов (0–5) → band.
- Перевод среднего 0–5 в band: `band = 1 + avg`, округление до 0.5, в пределах 1–6.

## AI-оценка

- Приоритет: серверная функция `/api/evaluate` (ключ в переменной окружения Vercel) → ключ пользователя (Anthropic, OpenAI, Gemini, DeepSeek) → только локальная оценка.
- Промпт содержит пересказ официальной рубрики, задание, ответ и локальные метрики. Ответ строго JSON: `score`, `criteria[]`, `strengths[]`, `fixes[]`, `corrections[]`, `improved`.
- Ключ пользователя по умолчанию хранится только в сессии вкладки.

## План подготовки

Вход: дата теста, текущий балл (или диагностика), цель, часы в неделю.
Выход: недели → дни → конкретные задания. Доля W/S ≥ 50 %. Mock-тесты в начале, в середине и за 5–7 дней до экзамена. Пропущенные дни переносятся.

## Данные

Всё в `localStorage` (без аккаунтов): попытки, настройки, план, журнал внешних тестов.
Экспорт/импорт JSON. Аудио хранится только в памяти текущей сессии.
